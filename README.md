# symbol-web-stylize

Веб-студия превращает обычный текст в символьный баннер и помогает подобрать оформление страницы. Проект создан для изучения Go, HTTP, доступного интерфейса и аккуратной интеграции LLM в программу, которая продолжает работать при сбое внешнего сервиса.

Всё необходимое для генерации баннеров встроено в исполняемый файл: три оригинальных шрифта, HTML, CSS и JavaScript. На сервере используются только стандартные пакеты Go. Установка библиотек JavaScript, ключ API и подключение к сети для демонстрации не нужны.

## Быстрый запуск

Нужен Go 1.26 или новее. Из корня репозитория:

```sh
go run ./cmd/server
```

Откройте `http://localhost:8080`. Введите `Hello`, выберите `standard`, `shadow` или `thinkertoy` и нажмите «Создать баннер». Поддерживаются печатные ASCII-символы и настоящие переносы строк; интерфейс объясняет это ограничение до отправки формы. `ADDR=:8081 go run ./cmd/server` меняет адрес.

Сборка самостоятельного файла:

```sh
go build -o server ./cmd/server
./server
```

После сборки файл можно запускать из другой папки. Шрифты и страницы не потеряются: они включены через `go:embed`.

## Оформление и доступность

Интерфейс построен от узкого экрана к широкому. CSS лежит отдельно в `static/css/`; встроенных `<style>` и `style`-атрибутов в HTML нет. Применение палитры меняет CSS-переменные через JavaScript. Область ASCII использует моноширинный шрифт и горизонтальную прокрутку: строки не ломают рисунок.

Пара «фон — текст» всегда проходит проверку WCAG AA, минимум 4,5:1. Неподходящий текст заменяется на чёрный или белый в зависимости от большего контраста. Для подписей цветных кнопок отдельно вычисляется читаемый цвет. Остальные цвета используются для декоративных элементов, а пояснения отображаются на проверенном фоне. Фокус хорошо виден с клавиатуры; сообщения об успехе и ошибках доступны через `role="status"` / `role="alert"`. При `prefers-reduced-motion` анимации отключаются.

Есть светлая и тёмная темы, собственный редактор пяти цветов, сохранение до 12 палитр и возврат к исходной теме. Выбранная палитра сохраняется в `localStorage`. Если браузер запрещает хранилище, тема применяется на текущей странице, а пользователь видит объяснение ограничения.

## Помощник по цвету

`POST /api/suggest-palette` принимает JSON:

```json
{"text":"Happy Birthday!"}
```

Ответ содержит `palettes` из трёх объектов: `name`, пять значений `colors`, `reasoning`, `mood`, `recommended`. Ровно один вариант рекомендован. Поле `mode` показывает `mock`, `ollama` или `openai`.

```sh
curl -s http://localhost:8080/api/suggest-palette \
  -H 'Content-Type: application/json' \
  -d '{"text":"Happy Birthday!"}'
```

Если `LLM_BASE_URL` отсутствует, включается **mock-режим**. Он возвращает воспроизводимые палитры без ключа и внешних запросов. Проверка цветов и контраста выполняется на том же пути, что и для настоящей модели. Это демонстрационный набор, а не имитация успешного ответа удалённого LLM.

Для настоящей модели задайте адрес и имя модели. В режиме Ollama приложение отправляет `POST <LLM_BASE_URL>/api/generate`, без потоковой выдачи. Если базовый адрес уже заканчивается на `/api`, добавляется только `/generate`.

```sh
export LLM_BASE_URL=http://127.0.0.1:11434
export LLM_MODEL=имя-вашей-установленной-модели
export LLM_PROVIDER=ollama
go run ./cmd/server
```

Для OpenAI-совместимого сервиса задайте `LLM_PROVIDER=openai`, его базовый адрес и модель; при необходимости — `LLM_API_KEY`. К адресу добавляется `/v1/chat/completions`, а при окончании `/v1` — `/chat/completions`. Старая переменная `LLM_PROTOCOL` поддерживается как совместимый псевдоним при отсутствии `LLM_PROVIDER`; разные значения двух переменных считаются ошибкой запуска. Значения `.env.example` — подсказка: сервер читает переменные окружения и сам файл `.env` не загружает. Адрес и модель в коде не зашиты. Адрес без имени модели останавливает запуск с понятной ошибкой. Имя модели без адреса оставляет mock-режим.

Промпт просит ровно три палитры в JSON, русское объяснение, настроение и контраст не ниже 4,5:1. Текст пользователя передаётся как экранированные данные. Ответ сервиса ограничен 128 КиБ и проверяется заново. Общий тайм-аут вызова — 10 секунд; при отказе или тайм-ауте API возвращает 503, а при некорректном ответе модели — 500 с понятным сообщением, а генератор баннеров продолжает работать. Ошибочный ввод даёт 400; ошибка подготовки страницы — 500. Перенаправления LLM запрещены, чтобы заголовок авторизации не уходил другому адресу.

## Память стиля — бонус

При каждом применении палитры браузер сохраняет её основной цвет. После третьего выбора вычисляются круговое среднее тона и средняя светлота HSL. Круговое среднее важно: 359° и 1° — близкие красные цвета, а обычное среднее ошибочно дало бы 180°.

Следующий запрос получает дополнительное поле:

```json
{"text":"Hello","preference":{"samples":3,"hue":20,"brightness":0.6}}
```

Сервер проверяет диапазоны, добавляет предпочтение в промпт и меняет основные цвета mock-палитр по тем же параметрам. Хранятся последние 30 применений. На странице видно состояние памяти; её можно очистить отдельно от сохранённых тем. Данные хранятся в браузере, базы персональных профилей нет.

## Помощник по тексту

Также сохранены возможности исходного `symbol-web`: `POST /api/suggest` — 3–5 продолжений текста, `POST /api/recommend-banner` — выбор шрифта по правилам, `POST /api/variations` — творческие варианты фразы (бонус). У LLM-запросов есть mock-режим и ограничение времени. Общий модуль находится в `internal/textai`, интерфейс — в `text-assist.js`.

## Ограничения и устойчивость

- Текст баннера: не более 4096 байт; результат: не более 1 МиБ. Имена шрифтов проверяются по разрешённому списку.
- Одновременно выполняются не более 8 реальных запросов палитр к LLM; превышение лимита даёт 503 без очереди.
- Палитра: непустой UTF-8-текст до 4096 байт; HTTP JSON-тело до 16 КиБ. Неизвестные поля, второе JSON-значение и некорректная память отклоняются.
- Сервер ограничивает время чтения, заголовки, простаивающие соединения; SIGINT/SIGTERM завершают работу через `Shutdown`.
- Шаблоны `html/template` экранируют пользовательский ввод. JavaScript использует `textContent`, а цвета принимает только как `#RRGGBB`.
- Повреждённое `localStorage` не ломает страницу. Хранилище тем ограничено 12 палитрами, история — 30 цветами.

Пределы защищают от обычных ошибочных и тяжёлых запросов. Приложение не обещает выдержать неограниченную сетевую нагрузку: для публичного размещения нужны ограничения запросов и TLS на внешнем сервере.

## Проверки

```sh
go test ./...
go test -race -count=1 ./...
go vet ./...
go test ./internal/ai -run=^$ -fuzz=FuzzContrast -fuzztime=5s
node --test static/js/palette.test.cjs
```

Node нужен только для дополнительных тестов JavaScript. Сборка и работа приложения от него не зависят. CI выполняет Go-проверки и тесты чистых функций браузерной логики. Проверяются контраст, ремонт палитры, mock, оба протокола LLM, испорченные ответы, отмена и недоступность сервиса, вредоносные формы, ограничения тела и 100 параллельных HTTP-сценариев.

Подробная карта требований и вопросы для защиты: [docs/AUDIT.md](docs/AUDIT.md). Порядок ручной проверки интерфейса: [docs/VERIFICATION.md](docs/VERIFICATION.md). Источник и контрольные суммы шрифтов: [FONTS.md](FONTS.md).

## Структура

```text
cmd/server/              запуск и корректное завершение сервера
internal/ascii/          проверка шрифтов и символьный рисунок
internal/ai/             LLM, mock, проверка цветов и контраста
internal/textai/         исходный помощник текста и выбора шрифта
internal/handlers/       формы, API и HTTP-ответы
static/css/              общий стиль, палитры и адаптивность
static/js/               взаимодействия, темы и память выбора
templates/              главная страница, результат и ошибка
standard.txt            исходный шрифт Standard
shadow.txt              исходный шрифт Shadow
thinkertoy.txt          исходный шрифт Thinkertoy
docs/                   подготовка к аудиту и проверки
```
